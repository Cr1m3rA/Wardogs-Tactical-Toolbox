战斗记录

怎么用（游戏内操作）
  1. 左边这张地图和游戏里的战术地图共用同一套坐标（1.00 = 100 m），所以你可以直接在图上点，也可以在游戏里 右键 → Mark Coordinates 复制坐标粘进来，两种混着用都行。
  2. 图上的塔楼（Tower）和三个出生点（Valkyra / Manticore / Lonestar）是社区标定的地标，用来对方向。
  3. 算完后：方位角 = 炮口罗盘方位（0°=北，90°=东）；RNG = 左边距离滑杆；密位 MIL = 右边仰角。
  4. 转到位、拨到位，先打一发试射，再用"修偏差"把弹坑喂回来。
地图说明：三张图（Bakurani / Ozeti / Zestafona）的底图瓦片已整份下载到本页同级的 tiles/ 目录 （z0–z7 全级，约 6.5 万张 / 1.6 GB），所以现在完全离线可用。 右上「底图」按钮可在 自动 / 本地 / 在线 之间切换：自动 = 本地优先、缺失才回退社区 CDN。 Bakurani 是经过实测标定的；Ozeti 的坐标读数尚未与游戏内完全核对（约 162 m 的偏移待确认）；Zestafona 的坐标标定未经实测。 直接用 file:// 双击打开时，部分浏览器会拦截本地图片；建议用 scripts/serve.cmd 起一个本地服务再访问。
射表与地图标定取自开源项目 apollyon-sys/wardogs-calculator （代码 MIT 许可；底图影像属于 WARDOGS 游戏资产，非 MIT，仅供个人参考使用）。 这是社区测量值，不是 Bulkhead 官方数据。计算假设炮位与目标等高，不处理地形起伏、建筑遮挡、风向与车辆倾斜； L81 自带 50 MOA 散布（685 m 处约 ±10 m），第一发永远是试射弹。
